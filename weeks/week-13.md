# 第 13 週：用 3 隻腳點亮整面看板

## 主題專案：位移暫存器與七段顯示器——省腳位的極致

> 🎯 **本週定位**：第 12 週的密碼門鎖把 18 隻腳全部用滿了。如果客戶還要 8 顆工作站指示燈、兩位數的計數器怎麼辦？這一週加入兩個新元件：
>
> - **位移暫存器 74HC595**：只用 **3 隻 Arduino 腳**，就能控制 **8 個輸出**；把好幾顆串在一起，**還是只用 3 隻腳**
> - **七段顯示器**：產線、電梯、計時器上最常見的數字顯示
>
> 74HC595 的輸出順序、串接順序、七段顯示器的段位，**全部都是接線決定的**——燈的方向反了、十位個位對調了，都只要改線。本週也會學到一個新的「改線就能解決」技巧：**兩顆按鈕並聯，任一顆按下都算**。
>
> 每一個關卡照「五個固定環節」進行：抽**客戶限制卡** → 回答**接線前決策題** → 照**接線任務**一步步接 → 套用**程式模板**（只改腳位區、參數區） → 完成**配線變化挑戰**（程式一個字都不改，只改線）。
>
> 🏁 **本週成果**：完成 **4 個關卡** ＋ **練習題 Lv.1～Lv.6**（套用本週的程式模板 T33～T36）。

## 認識新元件 ①：位移暫存器 74HC595

### 它在做什麼？

想像一台**電梯**：乘客（資料）一個一個走進去排好（位移），等 8 個人都進去了，**電梯門一打開**（鎖存），8 個人同時出現在樓層上（8 個輸出同時改變）。

```
Arduino                74HC595                     8 個輸出
資料線 ─────────────► 一個一個排進去 ────┐
時脈線 ─────────────► 「下一個！」        ├──► Q0 Q1 Q2 Q3 Q4 Q5 Q6 Q7
鎖存線 ─────────────► 「開門！」全部出現 ─┘
```

所以只要 **3 條線**：

| 名稱 | 白話 | 晶片腳 | 接 Arduino |
| --- | --- | --- | --- |
| 資料（DS） | 這一位是 1 還是 0 | Pin 14 | 任何數位腳 |
| 時脈（SHCP） | 「收下這一位，換下一位」 | Pin 11 | 任何數位腳 |
| 鎖存（STCP） | 「8 位都到齊了，一起顯示」 | Pin 12 | 任何數位腳 |

### 74HC595 接線地圖

晶片要**跨在麵包板中間的凹槽上**，有半圓缺口的一端朝上。左排由上往下 1～8，右排由下往上 9～16。

```
          ┌───∪───┐
   Q1  1 ─┤       ├─ 16  VCC（5V）
   Q2  2 ─┤       ├─ 15  Q0
   Q3  3 ─┤       ├─ 14  DS 資料 ◄── Arduino
   Q4  4 ─┤74HC595├─ 13  OE（接 GND）
   Q5  5 ─┤       ├─ 12  STCP 鎖存 ◄── Arduino
   Q6  6 ─┤       ├─ 11  SHCP 時脈 ◄── Arduino
   Q7  7 ─┤       ├─ 10  MR（接 5V）
  GND  8 ─┤       ├─  9  Q7' 串接輸出 ──► 下一顆的 DS
          └───────┘
```

| 晶片腳 | 名稱 | 白話說明 | 接到哪裡 |
| --- | --- | --- | --- |
| 16 | VCC | 晶片電源 | 5V |
| 8 | GND | 接地 | GND |
| 10 | MR | 清除全部（不要清除） | **5V** |
| 13 | OE | 輸出開關（一直開著） | **GND** |
| 14 | DS | 資料 | Arduino 數位腳 |
| 11 | SHCP | 時脈 | Arduino 數位腳 |
| 12 | STCP | 鎖存 | Arduino 數位腳 |
| 15、1～7 | Q0～Q7 | 8 個輸出 | 燈或七段顯示器（**每條串 220Ω**） |
| 9 | Q7' | 串接輸出 | 下一顆 74HC595 的 DS（Pin 14） |

> ⚠️ **最常見的錯誤**：Q0 在**右邊**的 Pin 15，不是左邊！Q1～Q7 才在左排的 Pin 1～7。

### 串接：再多燈也只要 3 隻腳

把第 1 顆的 **Q7'（Pin 9）** 接到第 2 顆的 **DS（Pin 14）**，兩顆的**時脈**和**鎖存**接在一起：

```
Arduino ──資料──► [第 1 顆] Q7' ──► [第 2 顆] Q7' ──► [第 3 顆]
        ──時脈──► 三顆的 SHCP（Pin 11）全部接在一起
        ──鎖存──► 三顆的 STCP（Pin 12）全部接在一起
```

| 74HC595 數量 | 輸出數量 | 佔 Arduino 幾隻腳 |
| --- | --- | --- |
| 1 顆 | 8 | 3 |
| 2 顆串接 | 16 | **還是 3** |
| 3 顆串接 | 24 | **還是 3** |

> 💡 **第 1 顆**＝最靠近 Arduino 的那顆（資料線直接接進來的那顆）。

### 74HC595 的限制

| 可以 | 不行 |
| --- | --- |
| 控制 LED 亮／滅 | 調光（沒有 `~` 功能） |
| 控制七段顯示器 | 讀取按鈕、感測器（它只能「輸出」） |
| 控制 RGB 的全亮全滅顏色 | 直接推動馬達（要經過 L293D） |

## 認識新元件 ②：七段顯示器

### 段位名稱

```
     ─a─
    │   │
    f   b
    │   │
     ─g─
    │   │
    e   c
    │   │
     ─d─   ● dp（小數點）
```

- 7 條燈管（a～g）＋1 個小數點（dp），一共 8 個段位——**剛好對應 74HC595 的 8 個輸出**。
- 本課程使用**共陰極**：共同腳接 GND，段位腳給「1」就亮。在 Tinkercad 點選七段顯示器，確認屬性是「Cathode」。

### 接法（經過 74HC595）

| 七段顯示器腳 | a | b | c | d | e | f | g | dp | 共同腳（COM） |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 接到 | Q0 | Q1 | Q2 | Q3 | Q4 | Q5 | Q6 | Q7 | GND |

每一段都經過 **220Ω**——每一段都是一顆小 LED，口訣「每條燈線一顆 220Ω」照樣適用。

### 不用 74HC595 會怎樣？

| 需求 | 直接接 Arduino | 用 74HC595 |
| --- | --- | --- |
| 1 位數字 | 8 隻腳 | 3 隻腳 |
| 2 位數字 | 16 隻腳 | 3 隻腳（2 顆串接） |
| 8 顆燈＋2 位數字 | 24 隻腳（**超過 18 隻，不可能**） | 3 隻腳（3 顆串接） |

## 燈號圖案：用 1 和 0 畫圖

本週模板用 `0b` 開頭的 8 位數字表示 8 顆燈：**1 代表亮、0 代表滅**，**最右邊是 Q0**。

```
0b 0 0 0 0 0 1 1 1
   ↑             ↑
   Q7            Q0

→ Q0、Q1、Q2 亮，其他滅
```

| 圖案 | 意思 |
| --- | --- |
| `0b00000001` | 只有 Q0 亮 |
| `0b10000000` | 只有 Q7 亮 |
| `0b11111111` | 全亮 |
| `0b10101010` | 隔一顆亮一顆 |
| `0b00011000` | 中間兩顆亮 |

> 🎨 你不需要會二進位換算，只要把它當成「一排 8 個開關」，想亮哪顆就在那個位置寫 1。本週的參數區有幾個「圖案」參數，改圖案就是改參數。

## 本週配線新技巧

### 技巧 1：燈的順序、十位個位的位置，都是「接線」決定的

| 現象 | 原因 | 修正（不改程式） |
| --- | --- | --- |
| 跑馬燈方向反了 | 燈在麵包板上的排列和 Q0～Q7 相反 | 把燈的接線順序反過來（Q0 接最左邊那顆……） |
| 計數 12 卻顯示 21 | 兩顆七段顯示器接反 | 對調兩顆七段顯示器的位置（或對調兩顆 74HC595 的輸出線） |
| 數字形狀怪怪的 | a～g 段位順序接錯 | 對照段位表重接 |

### 技巧 2：同一個輸出接兩顆燈（共腳的 74HC595 版）

和第 5 週「兩燈共腳」一樣，一個 Q 輸出可以接兩顆燈（**每顆各自串 220Ω**）。兩個七段顯示器的同一段也可以接在同一個 Q 上——**兩個看板顯示同一個數字**。

> ⚠️ 74HC595 每個輸出的電流有限，真實硬體上一個輸出最多接兩顆燈；Tinkercad 模擬沒問題。

### 技巧 3：兩顆按鈕並聯 → 任一顆按下都算

客戶要「路口兩邊各一顆行人按鈕」、「兩個地方都能按歸零」時：

```
5V ──┬── 按鈕① ──┐
     └── 按鈕② ──┼──► Arduino 腳位
                 └── 10kΩ ── GND（只要一顆）
```

- 兩顆按鈕的一端都接 5V、另一端都接到同一隻 Arduino 腳，**共用一顆 10kΩ** 下拉電阻。
- 任一顆按下，那隻腳都會變 HIGH——程式完全不用改，也不多佔腳。

## 配線口訣卡

| 口訣 | 說明 |
| --- | --- |
| ① **74HC595 跨凹槽、缺口朝上；16 接 5V、8 接 GND** | |
| ② **MR（10）接 5V、OE（13）接 GND** | 這兩隻漏接，晶片不會動 |
| ③ **DS（14）資料、SHCP（11）時脈、STCP（12）鎖存** 接 Arduino | 3 隻一般腳即可，不用 `~` |
| ④ **Q0 在右邊 Pin 15**，Q1～Q7 在左邊 Pin 1～7 | |

| ⑥ 七段：a～dp 依序接 Q0～Q7，每段一顆 220Ω，COM 接 GND | 屬性設成共陰極 |
| ⑦ 順序反了 → 改接線順序；兩處要同步 → 一個 Q 接兩顆燈 | 不用改程式 |
| ⑧ 兩處都要能按 → 兩顆按鈕並聯、共用一顆 10kΩ | 不多佔腳 |

## 共用工具

### 🔧 工具 1：74HC595 測試器

接好 74HC595 後先跑這支：依序只亮 Q0、Q1……Q7。串接多顆時，把 `chips` 改成顆數，會從第 1 顆的 Q0 一路測到最後一顆的 Q7。

```cpp
// ===== 改成你的腳位 =====
int dataPin  = 2;    // DS（Pin 14）
int clockPin = 3;    // SHCP（Pin 11）
int latchPin = 4;    // STCP（Pin 12）
int chips    = 1;    // 串接了幾顆 74HC595
// =======================

void sendOut(byte chip[], int n) {
  digitalWrite(latchPin, LOW);
  for (int i = n - 1; i >= 0; i--) shiftOut(dataPin, clockPin, MSBFIRST, chip[i]);
  digitalWrite(latchPin, HIGH);
}

void setup() {
  pinMode(dataPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
  pinMode(latchPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  byte chip[3];
  for (int c = 0; c < chips; c++) {
    for (int q = 0; q < 8; q++) {
      for (int i = 0; i < chips; i++) chip[i] = 0;
      chip[c] = 1 << q;
      sendOut(chip, chips);
      Serial.print("Chip ");
      Serial.print(c + 1);
      Serial.print("  Q");
      Serial.println(q);
      delay(400);
    }
  }
}
```

**檢查標準**：燈依 Q0 → Q7 的順序亮，和 Serial Monitor 一致。如果順序亂跳，檢查 Q0 是不是接到 Pin 15。

### 🔧 工具 2：七段顯示器測試器

接好七段顯示器後先跑這支：依序顯示 0～9。

```cpp
int dataPin = 2, clockPin = 3, latchPin = 4;   // ← 改成你的腳位

byte font[10] = {
  0b00111111, 0b00000110, 0b01011011, 0b01001111, 0b01100110,
  0b01101101, 0b01111101, 0b00000111, 0b01111111, 0b01101111
};

void setup() {
  pinMode(dataPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
  pinMode(latchPin, OUTPUT);
}

void loop() {
  for (int n = 0; n < 10; n++) {
    digitalWrite(latchPin, LOW);
    shiftOut(dataPin, clockPin, MSBFIRST, font[n]);
    digitalWrite(latchPin, HIGH);
    delay(800);
  }
}
```

**檢查標準**：數字形狀正確。如果「1」看起來像別的形狀，表示 a～g 的接線順序錯了。

// ===== 程式模板 T33：燈效招牌 =====

// ----- 腳位區（沒接的填 -1）-----
int dataPin  = ?;                   // 74HC595 DS（Pin 14）
int clockPin = ?;                   // 74HC595 SHCP（Pin 11）
int latchPin = ?;                   // 74HC595 STCP（Pin 12）
int btnMode  = ?;                   // 燈效切換鈕

// ----- 參數區 -----
int numLights  = 8;                 // 接了幾顆燈（從 Q0 開始算）
int numEffects = 4;                 // 按鈕可以切換幾種燈效（4：內建；5：再加自訂圖案）
byte custom[8] = {                  // 第 5 種燈效：自訂圖案（1 亮、0 滅，最右邊是 Q0）
  0b10000001, 0b01000010, 0b00100100, 0b00011000,
  0b00100100, 0b01000010, 0b00000000, 0b00000000
};
int customFrames = 6;               // 自訂圖案有幾格
int speedMs = 200;                  // 沒接旋鈕時，每一格停幾毫秒
int fastMs = 50, slowMs = 500;      // 旋鈕可調的範圍

// ----- 功能開關 -----

bool useKnob   = false;             // Step 3：速度旋鈕

// ===== 以下不用改 =====

void sendOut(byte chip[], int n) {
  digitalWrite(latchPin, LOW);
  for (int i = n - 1; i >= 0; i--) shiftOut(dataPin, clockPin, MSBFIRST, chip[i]);
  digitalWrite(latchPin, HIGH);
}

void setup() {
  pinMode(dataPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
  pinMode(latchPin, OUTPUT);
  if (btnMode >= 0) pinMode(btnMode, INPUT);
  Serial.begin(9600);
}

void loop() {
  if (useButton && btnMode >= 0) {
    int now = digitalRead(btnMode);
    if (now == HIGH && lastButton == LOW) {
      delay(50);
      effect = (effect + 1) % numEffects;
      step = 0;
      Serial.print("Effect: ");
      Serial.println(effect + 1);
    }
    lastButton = now;
  }

  int mask = (1 << numLights) - 1;                         // 只亮有接的燈
  int pattern = 0;
  if (effect == 0)      pattern = 1 << (step % numLights);             // 跑馬燈
  else if (effect == 1) pattern = (step % 2) ? 0b10101010 : 0b01010101; // 交錯閃
  else if (effect == 2) pattern = (1 << (step % (numLights + 1))) - 1;  // 堆疊
  else if (effect == 3) pattern = (step % 2) ? 0xFF : 0;                // 全閃
  else                  pattern = custom[step % customFrames];          // 自訂圖案

  byte chip[1] = { (byte)(pattern & mask) };
  sendOut(chip, 1);

  int wait = speedMs;
  if (useKnob && pinKnob >= 0) wait = map(analogRead(pinKnob), 0, 1023, fastMs, slowMs);
  step++;
  delay(wait);
}

## 關卡 2：學校前行人號誌（模板 T34）

// ----- 腳位區（沒接的填 -1）-----
int dataPin  = ?;                   // 74HC595 DS
int clockPin = ?;                   // 74HC595 SHCP
int latchPin = ?;                   // 74HC595 STCP
int ledRed   = ?;                   // 紅燈（等待）
int ledGreen = ?;                   // 綠燈（通行）
int btnWalk  = ?;                   // 請求按鈕
int pinBuzzer = ?;                  // 蜂鳴器

// ----- 參數區 -----

  0b00111111, 0b00000110, 0b01011011, 0b01001111, 0b01100110,
  0b01101101, 0b01111101, 0b00000111, 0b01111111, 0b01101111
};
int crossings = 0;

void sendOut(byte chip[], int n) {

  for (int i = n - 1; i >= 0; i--) shiftOut(dataPin, clockPin, MSBFIRST, chip[i]);
  digitalWrite(latchPin, HIGH);
}

  sendOut(chip, 1);
}

  if (useSound && pinBuzzer >= 0) tone(pinBuzzer, f, ms);
}

void setup() {
  pinMode(dataPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
  pinMode(latchPin, OUTPUT);

  if (ledGreen >= 0) pinMode(ledGreen, OUTPUT);

void loop() {
  if (!useButton) {                                        // Step 1：倒數展示
    for (int s = 9; s >= 0; s--) { showDigit(s); delay(800); }
    return;
  }

  digitalWrite(ledRed, HIGH);
  digitalWrite(ledGreen, LOW);
  showDigit(-1);

  if (digitalRead(btnWalk) == HIGH) {
    crossings++;
    Serial.print(signName + " request #");
    Serial.println(crossings);
    delay(waitTime);                                       // 等車道轉紅
    digitalWrite(ledRed, LOW);
    for (int s = min(walkTime, 9); s >= 0; s--) {
      showDigit(s);
      if (s > flashLast) {                                 // 一般綠燈
        digitalWrite(ledGreen, HIGH);
        beep(beepTone, 100);
        delay(1000);
      } else {                                             // 最後幾秒：綠燈閃、急促嗶
        for (int k = 0; k < 4; k++) {
          digitalWrite(ledGreen, k % 2 == 0 ? HIGH : LOW);
          beep(hurryTone, 60);
          delay(250);
        }
      }
    }
    digitalWrite(ledGreen, LOW);
  }
}

bool useReset  = false;             // Step 3：歸零鈕

// ===== 以下不用改 =====
byte font[10] = {
  0b00111111, 0b00000110, 0b01011011, 0b01001111, 0b01100110,
  0b01101101, 0b01111101, 0b00000111, 0b01111111, 0b01101111
};
int count = 0, tick = 0;
bool wasPassing = false, reached = false;
int lastCount = LOW, lastReset = LOW;

void sendOut(byte chip[], int n) {
  digitalWrite(latchPin, LOW);
  for (int i = n - 1; i >= 0; i--) shiftOut(dataPin, clockPin, MSBFIRST, chip[i]);
  digitalWrite(latchPin, HIGH);
}

void showNumber(int n, bool dot) {                         // 第 1 顆＝十位、第 2 顆＝個位
  byte chip[2];
  chip[0] = font[(n / 10) % 10];
  chip[1] = font[n % 10] | (dot ? 0b10000000 : 0);         // 個位的 Q7（小數點）
  sendOut(chip, 2);
}

float readCM(int trig, int echo) {
  digitalWrite(trig, LOW);  delayMicroseconds(2);
  digitalWrite(trig, HIGH); delayMicroseconds(10);
  digitalWrite(trig, LOW);
  long t = pulseIn(echo, HIGH, 30000);
  if (t == 0) return 999;
  return t / 58.0;
}

bool pressed(int pin, int &last) {
  if (pin < 0) return false;
  int now = digitalRead(pin);
  bool edge = (now == HIGH && last == LOW);
  last = now;
  if (edge) delay(50);
  return edge;
}

void setup() {
  pinMode(dataPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
  pinMode(latchPin, OUTPUT);
  if (pinTrig >= 0) { pinMode(pinTrig, OUTPUT); pinMode(pinEcho, INPUT); }
  if (btnCount >= 0) pinMode(btnCount, INPUT);
  if (btnReset >= 0) pinMode(btnReset, INPUT);
  Serial.begin(9600);
}

void loop() {
  tick++;
  bool hit = false;
  if (pinTrig >= 0) {
    bool passing = readCM(pinTrig, pinEcho) < passCM;
    hit = passing && !wasPassing;
    wasPassing = passing;
  } else {
    hit = pressed(btnCount, lastCount);
  }
  if (hit && count < 99) {
    count++;
    Serial.print("Count: ");
    Serial.println(count);
  }

  int target = (pinKnob >= 0) ? map(analogRead(pinKnob), 0, 1023, knobMin, knobMax) : fixedTarget;
  if (useTarget && count >= target && !reached) {
    reached = true;
    Serial.println("TARGET REACHED");
    if (pinBuzzer >= 0) { tone(pinBuzzer, 1047, 200); delay(250); tone(pinBuzzer, 1319, 400); }
  }
  if (count < target) reached = false;

  if (useReset && pressed(btnReset, lastReset)) {
    Serial.print("Shift output: ");
    Serial.print(count);
    Serial.println(" " + unitName);
    count = 0;
    reached = false;
  }

  int shown = (useTarget && countDown) ? max(target - count, 0) : count;
  bool dot = useTarget && reached && (tick / 5) % 2;
  showNumber(shown, dot);
  delay(50);
}

## 關卡 4：產線安燈總看板（模板 T36）

### 📖 情境

電子工廠有 8 個工作站，現場要一塊**安燈（Andon）總看板**：

> 🏭 **安燈（Andon）** 是豐田生產系統的核心工具：任何人發現問題都能「拉繩停線」，讓問題立刻被看見、被處理。

  else        { lcdP = new LiquidCrystal(lcdRS, lcdE, lcdD4, lcdD5, lcdD6, lcdD7); lcdP->begin(16, 2); }

  text = text.substring(0, 16);
  if (useI2C) { lcdI->setCursor(0, row); lcdI->print(text); }
  else        { lcdP->setCursor(0, row); lcdP->print(text); }

void sendOut(byte chip[], int n) {
  digitalWrite(latchPin, LOW);
  for (int i = n - 1; i >= 0; i--) shiftOut(dataPin, clockPin, MSBFIRST, chip[i]);
  digitalWrite(latchPin, HIGH);

void setup() {
  pinMode(dataPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
  pinMode(latchPin, OUTPUT);
  for (int s = 0; s < 8; s++) down[s] = false;
  if (useLCD) lcdStart();

void loop() {
  // ---- 鍵盤：站號 + # 切換異常／排除 ----
  char k = keypad.getKey();
  if (k >= '1' && k <= '0' + numStations) {
    input = String(k);
  } else if (k == '*') {
    input = "";
  } else if (k == '#' && input.length() == 1) {
    int s = input.toInt() - 1;
    down[s] = !down[s];
    Serial.print("STATION ");
    Serial.print(s + 1);
    if (down[s]) {
      events++;
      downSince[s] = millis();
      Serial.println(" DOWN");
    } else {
      Serial.print(" RECOVERED after ");
      Serial.print((millis() - downSince[s]) / 1000);
      Serial.println(" s");
    }
    input = "";
  }

  // ---- 站點燈：第 s 站異常 → 第 s 位為 1 ----
  byte stations = 0;

    if (down[s]) {
      stations |= (1 << s);
      downCount++;
      if (oldest < 0 || downSince[s] < downSince[oldest]) oldest = s;
    }
  }

  if (useCount) {
    byte chip[3] = { stations, font[(events / 10) % 10], font[events % 10] };
    sendOut(chip, 3);
    if (downCount > 0 && pinBuzzer >= 0 && millis() - lastBeep > (unsigned long)beepGap) {
      tone(pinBuzzer, 1500, 100);
      lastBeep = millis();
    }
  } else {
    byte chip[1] = { stations };
    sendOut(chip, 1);
  }

  if (useLCD) {
    if (oldest >= 0) showLine(0, "ST" + String(oldest + 1) + " DOWN " + String((millis() - downSince[oldest]) / 1000) + "s");
    else             showLine(0, boardName + ": ALL RUN");
    showLine(1, "DOWN NOW: " + String(downCount) + (input.length() ? "  >" + input : ""));
  }
  delay(30);
}

## 配線除錯站

| 現象 | 先檢查這裡 | 修正方式 |
| --- | --- | --- |
| 74HC595 的燈完全不亮 | 16、10 是否接 5V；8、13 是否接 GND | 補接電源、MR、OE |
| 燈的順序亂跳 | Q0 是否接在 Pin 15 | 對照晶片腳位圖 |
| 數字形狀怪 | a～g 是否依序接 Q0～Q6 | 用工具 2 對照 |
| 第 2 顆以後都不亮 | Q7'（9）→ 下一顆 DS（14）；時脈、鎖存是否並接 | 補接串接線 |
| 十位、個位顯示相反 | 兩顆七段接反 | 對調（技巧 1） |
| 一個 Q 接兩顆燈，一顆不亮 | 那顆燈是否有自己的 220Ω、方向是否接反 | 檢查電阻、長短腳 |
| 兩顆按鈕並聯後，一直被當成按下 | 是否有一顆按鈕接到 5V 與 GND 之間 | 兩顆按鈕都接「5V ↔ 訊號腳」 |
| 程式無法上傳 | 腳位區是否還有 `?` 沒填 | 用到的填腳位，沒接的填 `-1` |

## 反思與延伸討論

1. 74HC595 讓「3 隻腳控制 24 個輸出」成為可能，但它不能調光、不能讀輸入。在你的期末專題中，哪些元件適合交給 74HC595、哪些一定要接 Arduino？
2. 本週的「順序反了 → 改線」和第 10 週的「馬達方向反了 → 改線」，背後是同一個道理。請用一句話說明：什麼樣的問題適合用「改線」解決？
3. 安燈系統的價值不在燈，而在「問題被看見之後的處理流程」。如果燈亮了卻沒人來處理，這套系統還有價值嗎？
