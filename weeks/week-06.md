# 第 6 週：溫度監控的智慧場域

## 主題專案：讓系統「感覺冷熱」並守住溫度

> 🎯 **本週定位**：上週系統學會了「看光線」，這一週再加一個感官：**溫度感測器 TMP36**。溫度是工業與服務業最常監控的數據之一——藥品、食材、機房、溫室、冷鏈物流，溫度一旦失控，損失往往很大。

>
> 🏁 **本週成果**：完成 **4 個關卡** ＋ **練習題 Lv.1～Lv.6**（套用本週的程式模板 T9～T12）。

## 認識新元件：溫度感測器 TMP36

### 外觀與接法

TMP36 有 **3 隻腳**，外觀和旋鈕一樣是「左、中、右」，但它**有方向性，不能接反**：

> **平面朝向自己：左腳 5V、中間接 A 腳、右腳 GND。**

| TMP36 的腳（平面朝自己） | 接到哪裡 |
| --- | --- |
| 左腳 | 5V |
| **中間腳** | **A0～A5 其中一隻** |
| 右腳 | GND |

- TMP36 **不需要**電阻。
- 在 Tinkercad 把滑鼠移到腳上，會顯示該腳名稱（Power／Vout／GND），**接線前先確認一次**。
- ⚠️ 旋鈕的左右腳接反只會「方向相反」，但 **TMP36 接反會讀到錯誤溫度**（真實硬體上還會發燙損壞）。所以**本週的配線變化挑戰，沒有任何一題可以靠「把 TMP36 反接」來解決**。
- 開始模擬後，**點一下 TMP36**，會出現溫度滑桿，拖曳它就能模擬變冷或變熱（範圍 −40～125°C）。

### 讀值怎麼變成攝氏溫度？

本週所有模板都附上同一個「翻譯機」函式，你**不需要修改它**：

```cpp
float readC(int pin) {
  float voltage = analogRead(pin) * 5.0 / 1023.0;   // 讀值 → 電壓
  return (voltage - 0.5) * 100.0;                    // 電壓 → °C
}
```

> 💡 `float` 是「可以有小數點的數字」，所以參數區的溫度可以寫成 `2.0`、`7.5`。

### 🧭 四種「A 腳輸入元件」比一比

| 元件 | 誰來改變數值？ | 需要 10kΩ 嗎？ | 接反會怎樣？ |
| --- | --- | --- | --- |
| 按鈕 | 人按下 | 要 | — |
| 旋鈕 | 人轉動 | 不用 | 方向相反，**可以利用** |
| 光敏電阻 | 環境光線 | 要 | 和 10kΩ 對調讀值反過來，**可以利用** |
| **TMP36** | **環境溫度** | **不用** | **讀值錯誤，絕對不可以** |

## 三種警報處理方式

溫度異常時，系統要怎麼反應？本週的四個模板分別示範三種方式，選哪一種是**管理決策**：

| 方式 | 異常消失後 | 適合情境 | 本週模板 |
| --- | --- | --- | --- |
| **自動恢復** | 燈號、聲音自己恢復正常 | 異常不嚴重、只需要讓人知道（嬰兒房、溫室通風） | T10 |
| **靜音但保留燈號** | 人可以先關掉聲音去處理，但異常燈號一直亮到恢復正常 | 需要有人處理，但吵鬧會干擾工作（藥品冷藏櫃、貨車） | T9、T12 |
| **鎖定＋人工復歸** | 就算恢復正常也繼續警報，必須有人確認後按復歸 | 異常可能造成重大損失，必須留下「有人處理過」的紀錄（機房） | T11 |

## 配線口訣卡

| 口訣 | 說明 |
| --- | --- |
| ① **TMP36：平面朝自己，左 5V、中 A 腳、右 GND** | 不用電阻，**絕對不能接反** |
| ② 要調亮度、混中間色 → 接 `~` 腳 | 只有 3、5、6、9、10、11 |
| ③ 有蜂鳴器時，需要調光的燈避開 3、11 | 從 5、6、9、10 裡挑 |
| ④ 黃色（255,180,0）只有**綠色腳**需要調光 | 紅色腳只有 0 或 255，可接一般腳 |
| ⑤ 每條燈線一顆 220Ω；蜂鳴器、旋鈕、TMP36 不用 | 兩燈共腳時每顆各自一顆 220Ω |
| ⑥ 按鈕、光敏電阻各配一顆 10kΩ | |
| ⑦ Pin 0、1 先不要用；腳位不夠時借 A 腳 | A 腳也能接燈、按鈕、蜂鳴器 |
| ⑧ 方向反了 → 先改線，不改程式 | 但 **TMP36 不在此限** |

> 💡 **口訣④是本週新技巧**：RGB 的每一隻顏色腳是分開的。仔細看你要用的顏色，**哪一隻腳會出現 0 和 255 以外的數字，只有那一隻需要 `~` 腳**。例如綠 (0,255,0)、黃 (255,180,0)、紅 (255,0,0) 三種顏色，只有 G 腳出現 180，所以只有 G 需要 `~` 腳。

## 共用工具

### 🔧 工具 1：溫度讀值檢查器

接好 TMP36 後先跑這支。拖曳 Tinkercad 的溫度滑桿，確認 Serial Monitor 顯示的 °C **跟滑桿上的溫度差不多**。

```cpp
int pinTemp = A0;   // ← 改成你 TMP36 中間腳接的 A 腳

float readC(int pin) {
  float voltage = analogRead(pin) * 5.0 / 1023.0;
  return (voltage - 0.5) * 100.0;
}

void setup() {
  Serial.begin(9600);
}

void loop() {
  Serial.print("Temp: ");
  Serial.print(readC(pinTemp));
  Serial.println(" C");
  delay(300);
}
```

**檢查標準**：滑桿拉到 25°C，顯示約 24～26°C。如果差了幾十度，**先檢查 TMP36 有沒有接反**。

### 🔧 工具 2：接線驗證器（沿用前幾週）

```cpp
int pins[] = { 9, 10, 11 };   // ← 填入所有「燈」的腳位（不含蜂鳴器）
int numPins = 3;

void setup() {
  Serial.begin(9600);
  for (int i = 0; i < numPins; i++) pinMode(pins[i], OUTPUT);
}

void loop() {
  for (int i = 0; i < numPins; i++) {
    Serial.print("Testing Pin ");
    Serial.println(pins[i]);
    digitalWrite(pins[i], HIGH);
    delay(500);
    digitalWrite(pins[i], LOW);
  }
  Serial.println("---");
  delay(1000);
}
```

## 關卡 1：藥品冷藏櫃溫度監測（模板 T9）

⭐ **難度**：TMP36 ＋ 三顆燈，再逐步加蜂鳴器與靜音鈕

### 📖 情境

社區藥局的冷藏櫃必須維持在指定溫度範圍內。溫度太低亮藍燈、正常亮綠燈、太高亮紅燈；超出範圍時蜂鳴器嗶嗶叫。藥師聽到警報後，可以按「靜音鈕」先關掉聲音去處理，但**異常燈號要繼續亮著**，直到溫度回到正常範圍。

### 🎯 本關配線學習目標

- 第一次接 TMP36：確認方向、選 A 腳
- 依客戶需求決定「要不要接某顆燈」

### 🃏 ① 客戶限制卡

| 限制卡 | 現場條件 |
| --- | --- |
| **A** | 疫苗冷藏櫃 **2～8°C**；三顆燈（太低藍、正常綠、太高紅）都要 |
| **B** | 一般藥品常溫櫃 **15～25°C**；靜音鈕必須接 **A3**；TMP36 必須接 **A2** |
| **C** | 冷藏櫃 **2～8°C**，但客戶說「太低的問題由壓縮機自己處理，我們只監控**太高**」——**不接太低燈**、太低也不要叫；Pin 2～5 已被佔用 |

### ✏️ ② 接線前決策題

1. TMP36 需要電阻嗎？三顆燈需要 `~` 腳嗎？本關一共要幾顆 220Ω、幾顆 10kΩ？
2. 平面朝向自己時，TMP36 左、中、右各接哪裡？在 Tinkercad 你會用什麼方法再確認一次？
3. 限制卡 C：不接太低燈，`ledLow` 要填什麼？還有哪個參數要改，才能讓「太低」時不叫？
4. 填好溫度規格表。

**溫度規格表**：

| 項目 | 數值 |
| --- | --- |
| 下限 `lowLimit` | |
| 上限 `highLimit` | |
| 太低時要叫嗎？ `beepLow` | |
| 太高時要叫嗎？ `beepHigh` | |

**腳位規劃表**：

| 元件 | 腳位 |
| --- | --- |
| TMP36（中間腳） | |

### 🔌 ③ 接線任務

**Step 1：TMP36＋三顆燈**

1. TMP36 放在麵包板左側，**平面朝向你**，左腳接 5V、右腳接 GND、中間腳接 A 腳。
2. 滑鼠移到三隻腳上，確認名稱是 Power／Vout／GND。
3. 三顆燈由左到右依「藍、綠、紅」排列，各串 220Ω。
4. ✅ 檢查：**工具 1** 確認溫度正確；**工具 2** 確認三顆燈。

**Step 2：加上蜂鳴器**

1. 蜂鳴器正極接你規劃的腳位，負極接 GND。
2. ✅ 檢查：蜂鳴器測試器。

**Step 3：加上靜音鈕**

1. 接法同前（10kΩ 下拉）。
2. ✅ 檢查：麵包板分成「感測區」「燈號區」「操作區」。

### 💻 ④ 套用程式模板 T9

```cpp
// ===== 程式模板 T9：溫度範圍監測（靜音但保留燈號） =====

// ----- 腳位區（沒接的元件填 -1）-----
int pinTemp   = A0;                 // TMP36
int ledLow    = ?;                  // 太低燈
int ledOK     = ?;                  // 正常燈
int ledHigh   = ?;                  // 太高燈
int pinBuzzer = ?;                  // 蜂鳴器
int pinMute   = ?;                  // 靜音鈕

// ----- 參數區 -----
float lowLimit  = 2.0;              // 下限 °C
float highLimit = 8.0;              // 上限 °C
bool beepLow  = true;               // 太低時要不要叫
bool beepHigh = true;               // 太高時要不要叫
int beepTone  = 1200;               // 嗶聲音高
String placeName = "Fridge";        // 顯示名稱（英文）

// ----- 功能開關 -----
bool useBuzzer = false;             // Step 2
bool useMute   = false;             // Step 3

// ===== 以下不用改 =====
bool muted = false;
int lastButton = LOW;

float readC(int pin) {
  float voltage = analogRead(pin) * 5.0 / 1023.0;
  return (voltage - 0.5) * 100.0;
}

void setLed(int pin, bool on) {
  if (pin >= 0) digitalWrite(pin, on ? HIGH : LOW);
}

void setup() {
  if (ledLow >= 0)  pinMode(ledLow, OUTPUT);
  if (ledOK >= 0)   pinMode(ledOK, OUTPUT);
  if (ledHigh >= 0) pinMode(ledHigh, OUTPUT);
  if (useMute) pinMode(pinMute, INPUT);
  Serial.begin(9600);
}

void loop() {
  float t = readC(pinTemp);
  bool tooLow  = t < lowLimit;
  bool tooHigh = t > highLimit;
  bool ok = !tooLow && !tooHigh;

  setLed(ledLow, tooLow);
  setLed(ledOK, ok);
  setLed(ledHigh, tooHigh);

  if (ok) muted = false;                       // 恢復正常，靜音自動取消

  if (useMute) {
    int now = digitalRead(pinMute);
    if (now == HIGH && lastButton == LOW) {
      delay(50);
      if (!ok) { muted = true; Serial.println("Alarm muted"); }
    }
    lastButton = now;
  }

  bool needBeep = (tooLow && beepLow) || (tooHigh && beepHigh);
  if (useBuzzer && needBeep && !muted) tone(pinBuzzer, beepTone, 150);

  Serial.print(placeName + ": ");
  Serial.print(t);
  Serial.println(ok ? " C  OK" : tooLow ? " C  TOO LOW" : " C  TOO HIGH");
  delay(500);
}
```

**本關要改的地方**：

| 區塊 | 要做什麼 |
| --- | --- |

| 參數區 | 依溫度規格表修改 `lowLimit`、`highLimit`、`beepLow`、`beepHigh` |

```cpp
// ===== 程式模板 T10：溫控輸出（自動恢復） =====

// ----- 腳位區（沒接的元件填 -1）-----
int pinTemp  = A0;                  // TMP36
int pinKnob  = A1;                  // 目標溫度旋鈕
int pinLDR   = A2;                  // 日夜偵測光敏電阻
int pinPower = ?;                   // 風扇或加熱器（LED 亮度代表強度）
int pinR = ?, pinG = ?, pinB = ?;   // 狀態 RGB

// ----- 參數區 -----
bool coolingMode = true;            // true：太熱才開（通風）；false：太冷才開（加熱）
int targetDefault = 25;             // 沒接旋鈕時的目標溫度
int targetMin = 20, targetMax = 35; // 旋鈕可調範圍
int gain = 50;                      // 每偏離 1°C，輸出增加多少（0~255）
int minPower = 0;                   // 一開始運轉時的最低輸出
int nightOffset = -5;               // 夜間目標溫度調整（負數＝降低）
int darkLine = 300;                 // 光線低於這個數字算夜間
int colorIdle[3]    = { 0, 255, 0 };   // 白天待機（綠）
int colorRunning[3] = { 255, 180, 0 }; // 白天運轉中（黃）
int colorNight[3]   = { 0, 0, 255 };   // 夜間（藍）

// ----- 功能開關 -----
bool useKnob  = false;              // Step 2
bool useNight = false;              // Step 3：光敏電阻
bool useRGB   = false;              // Step 3：RGB

// ===== 以下不用改 =====
float readC(int pin) {
  float voltage = analogRead(pin) * 5.0 / 1023.0;
  return (voltage - 0.5) * 100.0;
}

void setColor(int c[]) {
  analogWrite(pinR, c[0]);
  analogWrite(pinG, c[1]);
  analogWrite(pinB, c[2]);
}

void setup() {
  pinMode(pinPower, OUTPUT);
  if (useRGB) { pinMode(pinR, OUTPUT); pinMode(pinG, OUTPUT); pinMode(pinB, OUTPUT); }
  Serial.begin(9600);
}

void loop() {
  float t = readC(pinTemp);
  int target = useKnob ? map(analogRead(pinKnob), 0, 1023, targetMin, targetMax) : targetDefault;

  bool night = useNight && (analogRead(pinLDR) < darkLine);
  if (night) target += nightOffset;

  float diff = coolingMode ? (t - target) : (target - t);
  int power = 0;
  if (diff > 0) power = constrain(minPower + (int)(diff * gain), 0, 255);
  analogWrite(pinPower, power);

  if (useRGB) {
    if (night)          setColor(colorNight);
    else if (power > 0) setColor(colorRunning);
    else                setColor(colorIdle);
  }

  Serial.print("Temp: ");
  Serial.print(t);
  Serial.print(" C   Target: ");
  Serial.print(target);
  Serial.print(night ? " C (NIGHT)   Power: " : " C   Power: ");
  Serial.println(power);
  delay(300);
}
```

| 區塊 | 要做什麼 |
| --- | --- |
| 腳位區 | 依腳位規劃表填入；注意三個 A 腳不要填錯 |
| 參數區 | 依溫控規格表修改 `coolingMode`、`targetMin`、`targetMax`、`nightOffset`、`darkLine` |
| 功能開關 | Step 2 → `useKnob = true`；Step 3 → `useNight = true`、`useRGB = true` |

```cpp
// ===== 程式模板 T11：三段溫度警報（鎖定＋人工復歸） =====

// ----- 腳位區（沒接的元件填 -1）-----
int pinTemp   = A0;                 // TMP36
int pinR = ?, pinG = ?, pinB = ?;   // 狀態 RGB
int pinBuzzer = ?;                  // 蜂鳴器
int pinReset  = ?;                  // 復歸鈕

// ----- 參數區 -----
float warnLine   = 30.0;            // 警戒線 °C
float dangerLine = 35.0;            // 危險線 °C
bool alarmWhenHigh = true;          // true：越熱越危險；false：越冷越危險
bool latch = true;                  // true：危險後鎖定，要按復歸
int colorOK[3]     = { 0, 255, 0 };     // 正常（綠）
int colorWarn[3]   = { 255, 180, 0 };   // 警戒（黃）
int colorDanger[3] = { 255, 0, 0 };     // 危險（紅）
int warnTone   = 1000;              // 警戒嗶聲音高
int dangerTone = 2000;              // 危險鳴叫音高
String placeName = "Server room";   // 顯示名稱

// ----- 功能開關 -----
bool useBuzzer = false;             // Step 2
bool useReset  = false;             // Step 3

// ===== 以下不用改 =====
bool latched = false;
int events = 0, lastButton = LOW, tick = 0;

float readC(int pin) {
  float voltage = analogRead(pin) * 5.0 / 1023.0;
  return (voltage - 0.5) * 100.0;
}

void setColor(int c[]) {
  analogWrite(pinR, c[0]);
  analogWrite(pinG, c[1]);
  analogWrite(pinB, c[2]);
}

void setup() {
  pinMode(pinR, OUTPUT); pinMode(pinG, OUTPUT); pinMode(pinB, OUTPUT);
  if (useReset) pinMode(pinReset, INPUT);
  Serial.begin(9600);
}

void loop() {
  tick++;
  float t = readC(pinTemp);
  int level = 0;                                       // 0=正常, 1=警戒, 2=危險
  if (alarmWhenHigh) {
    if (t >= dangerLine) level = 2; else if (t >= warnLine) level = 1;
  } else {
    if (t <= dangerLine) level = 2; else if (t <= warnLine) level = 1;
  }

  if (latch && useReset) {
    if (level == 2 && !latched) {
      latched = true;
      events++;
      Serial.print("DANGER EVENT #");
      Serial.println(events);
    }
    int now = digitalRead(pinReset);
    if (now == HIGH && lastButton == LOW) {
      delay(50);
      if (latched && level < 2) { latched = false; Serial.println("Reset by engineer"); }
      else if (latched)         { Serial.println("Cannot reset: still in danger"); }
    }
    lastButton = now;
  }

  int show = (latched) ? 2 : level;
  if (show == 0) {
    setColor(colorOK);
    noTone(pinBuzzer);
  } else if (show == 1) {
    setColor(colorWarn);
    if (useBuzzer && tick % 4 == 0) tone(pinBuzzer, warnTone, 100);
  } else {
    setColor(colorDanger);
    if (useBuzzer) tone(pinBuzzer, dangerTone);
  }

  Serial.print(placeName + ": ");
  Serial.print(t);
  Serial.println(" C");
  delay(300);
}

// ===== 程式模板 T12：雙區溫度看板（靜音但保留燈號） =====

// ----- 腳位區（沒接的元件填 -1）-----
int tempA = A0, tempB = A1;              // 區域 A、B 的 TMP36
int ledA[3] = { ?, ?, ? };               // 區域 A：綠、黃、紅
int ledB[3] = { ?, ?, ? };               // 區域 B：綠、黃、紅
int pinR = ?, pinG = ?, pinB = ?;        // 總狀態 RGB
int pinBuzzer = ?;                       // 蜂鳴器
int pinAck    = ?;                       // 確認鈕

// ----- 參數區 -----
String nameA = "Chill", nameB = "Freeze";   // 區域名稱（英文）
float okLowA = 0,   okHighA = 7,   warnA = 2;   // 區域 A 正常範圍與黃燈寬度
float okLowB = -40, okHighB = -18, warnB = 3;   // 區域 B 正常範圍與黃燈寬度
int colorOK[3]   = { 0, 255, 0 };
int colorWarn[3] = { 255, 180, 0 };
int colorBad[3]  = { 255, 0, 0 };
int alarmTone = 1800;

// ----- 功能開關 -----
bool useZoneB = false;                   // Step 2
bool useAck   = false;                   // Step 3

// ===== 以下不用改 =====
bool acked = false;
int lastButton = LOW;

float readC(int pin) {
  float voltage = analogRead(pin) * 5.0 / 1023.0;
  return (voltage - 0.5) * 100.0;
}

int levelOf(float t, float lo, float hi, float band) {
  if (t >= lo && t <= hi) return 0;
  if (t >= lo - band && t <= hi + band) return 1;
  return 2;
}

void showLevel(int leds[], int level) {
  for (int i = 0; i < 3; i++) digitalWrite(leds[i], (i == level) ? HIGH : LOW);
}

void setColor(int c[]) {
  analogWrite(pinR, c[0]);
  analogWrite(pinG, c[1]);
  analogWrite(pinB, c[2]);
}

void setup() {
  for (int i = 0; i < 3; i++) pinMode(ledA[i], OUTPUT);
  if (useZoneB) for (int i = 0; i < 3; i++) pinMode(ledB[i], OUTPUT);
  pinMode(pinR, OUTPUT); pinMode(pinG, OUTPUT); pinMode(pinB, OUTPUT);
  if (useAck) pinMode(pinAck, INPUT);
  Serial.begin(9600);
}

void loop() {
  float ta = readC(tempA);
  int la = levelOf(ta, okLowA, okHighA, warnA);
  showLevel(ledA, la);
  int worst = la;

  float tb = 0;
  if (useZoneB) {
    tb = readC(tempB);
    int lb = levelOf(tb, okLowB, okHighB, warnB);
    showLevel(ledB, lb);
    if (lb > worst) worst = lb;
  }

  if (worst == 0)      setColor(colorOK);
  else if (worst == 1) setColor(colorWarn);
  else                 setColor(colorBad);

  if (worst < 2) acked = false;
  if (useAck) {
    int now = digitalRead(pinAck);
    if (now == HIGH && lastButton == LOW) {
      delay(50);
      if (worst == 2) { acked = true; Serial.println("Driver acknowledged"); }
    }
    lastButton = now;
  }
  if (worst == 2 && !acked) tone(pinBuzzer, alarmTone, 200);

  Serial.print(nameA + ": ");
  Serial.print(ta);
  if (useZoneB) { Serial.print(" C   " + nameB + ": "); Serial.print(tb); }
  Serial.println(" C");
  delay(400);
}
```

| 參數區 | 依溫度規格表修改兩個區域的範圍、`warnA`、`warnB`、名稱 |

| 溫度和滑桿差幾十度，或拖曳滑桿幾乎不變 | TMP36 是否接反 | 平面朝自己：左 5V、中 A 腳、右 GND；滑鼠移到腳上確認名稱 |
| 溫度亂跳，或一直顯示 −50°C 左右 | 中間腳沒接到 A 腳，或 A 腳編號和程式不一致 | 用工具 1 確認 |
| 拉 A 區的滑桿，卻是 B 區的燈在變 | 兩顆 TMP36 的 A 腳是否接反 | 用工具 1 逐一確認 |
| 黃色看起來像紅色或怪怪的 | G 腳是否接在 `~` 腳；是否被蜂鳴器借走（3、11） | 依口訣④把 G 接到可用的 `~` 腳 |
| 風扇 LED 只有全亮全滅 | 是否接在 `~` 腳 | 改接 `~` 腳 |
| 按復歸鈕沒反應 | 功能開關是否打開；溫度是否還在危險區 | 先回到安全範圍再按 |
| 程式無法上傳 | 腳位區是否還有 `?` 沒填 | 用到的填腳位，沒接的填 `-1` |

## 📖 本週詞彙表

| 名稱 | 白話解釋 |
| --- | --- |
| 溫度感測器 TMP36 | 依溫度輸出不同數值的三腳元件，有方向性、不用電阻 |
| `readC()` 溫度翻譯機 | 模板內建的函式，把讀值換算成攝氏溫度 |
| `float` 浮點數 | 可以有小數點的數字，例如 24.85 |
| 正常範圍／偏離帶 | 規格內、接近規格邊界的溫度範圍 |
| 自動恢復 | 異常消失後自動回到正常顯示 |
| 靜音（Acknowledge） | 只關掉聲音，異常燈號仍保留 |
| 鎖定與人工復歸（Latch & Reset） | 異常後持續警報，需要有人確認且狀況恢復才能解除 |
| 逐腳判斷 `~` 腳 | RGB 的每隻顏色腳分開看，只有出現中間值的腳需要 `~` |

## 反思與延伸討論

1. 本週出現了三種警報處理方式。請說明你怎麼判斷一個情境該用哪一種，並各舉一個本週以外的例子。
2. 本週的配線變化挑戰中，有幾題是「找出老師動過手腳的地方」。在真實工作中，「系統出問題時，從現象反推原因」是很重要的能力。你用了什麼步驟找出問題？
3. 本週每個情境的溫度範圍都是「別人給的」。如果客戶自己也不知道該訂多少度，身為顧問，你會透過哪些管道找出合理的規格？
