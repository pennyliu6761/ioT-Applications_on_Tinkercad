## 主題專案：讓系統從「提醒」變成「動手」

> 🎯 **本週定位**：前六週的系統只會「亮燈、出聲」提醒人。這一週加入 **伺服馬達（Servo）**，系統第一次可以自己「動手」——開柵欄、轉天窗、推擋板、關門。

## 認識新元件：伺服馬達

### 外觀與接法

伺服馬達有 **3 條線**，靠**顏色**分辨，不需要電阻：

| 線的顏色 | 名稱 | 接到哪裡 |
| --- | --- | --- |
| 橘色（或黃色） | 訊號 | 任何一隻數位腳位（也可以借 A 腳） |
| 紅色 | 電源 | 5V |
| 棕色（或黑色） | 接地 | GND |

- 伺服的訊號線**接一般腳位就可以**，不需要 `~` 腳。
- 在 Tinkercad 元件庫搜尋「Micro Servo」，開始模擬後可以看到白色擺臂實際轉動。
- 多顆伺服時，每顆的紅線、棕線都接到麵包板電源軌，橘線各自接不同腳位。

### 🔧 本週配線新技巧：兩顆伺服共用一條訊號線

客戶要「兩扇門同時開關」時：

```
Arduino 腳位 ──┬── 伺服① 橘線
               └── 伺服② 橘線
（兩顆的紅線都接 5V、棕線都接 GND）
```

- 兩顆伺服會**轉到完全相同的角度**。
- 真實硬體上，兩顆以上伺服建議用獨立電源；Tinkercad 模擬可以直接接。

### 伺服的「方向」不能靠改線反轉

旋鈕、光敏電阻可以靠改線反轉方向，但**伺服不行**——對調紅、棕線只會讓它不動（真實硬體還會損壞）。伺服的「0 度是開還是關」要靠**參數區的角度**決定，所以每個關卡都要先用**伺服測試器**找出角度。

## ~ 腳可用表

伺服馬達會借走 `~9`、`~10` 的調光功能（不管伺服本身接在哪一隻腳）。和蜂鳴器疊在一起，就得到這張表：

| 系統裡有…… | 還能調光、混中間色的 `~` 腳 |
| --- | --- |
| 都沒有 | 3、5、6、9、10、11 |
| 只有蜂鳴器 | 5、6、9、10 |
| 只有伺服 | 3、5、6、11 |
| **伺服＋蜂鳴器** | **只剩 5、6** |

> 💡 被借走的 `~` 腳仍然可以接**伺服本身**、**按鈕**、**全亮全滅的燈**、**蜂鳴器**——它只是不能調光而已。善用第 5、6 週學的「全亮全滅顏色接一般腳」和「逐腳判斷」，`~` 腳不夠時通常都有解。

## 配線口訣卡

| 口訣 | 說明 |
| --- | --- |
| ① **伺服：橘訊號、紅 5V、棕 GND** | 訊號接一般腳位即可，不用電阻 |
| ② **有伺服，9、10 不能調光；有蜂鳴器，3、11 不能調光** | 兩者都有時只剩 5、6 |
| ③ 逐腳判斷：只有出現中間值的顏色腳需要 `~` | 綠 (0,255,0)、紅 (255,0,0) 全部不用 |
| ④ 兩扇門同步 → 兩顆伺服共用一條訊號線 | 紅、棕線各自接電源軌 |
| ⑤ 每條燈線一顆 220Ω；伺服、蜂鳴器、旋鈕、TMP36 不用 | 兩燈共腳時每顆各自一顆 |
| ⑥ 按鈕、光敏電阻各配一顆 10kΩ | TMP36 平面朝自己：左 5V、中 A 腳、右 GND |
| ⑦ Pin 0、1 不用；腳位不夠時借 A 腳 | A 腳也能接伺服、燈、按鈕、蜂鳴器 |
| ⑧ 伺服方向 → 改參數區角度，不是改線 | 其他方向問題仍先改線 |

## 共用工具

### 🔧 工具 1：伺服測試器

接好伺服後先跑這支，確認擺臂會依序轉到 0°、90°、180°，並**記錄哪個角度對應到哪個狀態**——參數區的角度要依這張表填。

```cpp
#include <Servo.h>

int pinServo = 6;   // ← 改成你伺服訊號線接的腳位
Servo test;

void setup() {
  Serial.begin(9600);
  test.attach(pinServo);
}

void loop() {
  int angles[] = { 0, 90, 180, 90 };
  for (int i = 0; i < 4; i++) {
    Serial.print("Angle: ");
    Serial.println(angles[i]);
    test.write(angles[i]);
    delay(1200);
  }
}
```

**角度記錄表**（每次接伺服都要填）：

| 伺服 | 接在 | 「關／收」角度 | 「開／推出」角度 |
| --- | --- | --- | --- |
| 第 1 顆 | Pin ? | | |
| 第 2 顆 | Pin ? | | |

### 🔧 工具 2：接線驗證器（沿用前幾週）

```cpp
int pins[] = { 9, 10, 11 };   // ← 填入所有「燈」的腳位（不含伺服、蜂鳴器）
int numPins = 3;

void setup() {
  Serial.begin(9600);
  for (int i = 0; i < numPins; i++) pinMode(pins[i], OUTPUT);
}

void loop() {
  for (int i = 0; i < numPins; i++) {
    Serial.print("Testing Pin ");
    Serial.println(pins[i]);

  Serial.println("---");
  delay(1000);
}
```

## 關卡 1：停車場出入口柵欄（模板 T13）

⭐ **難度**：按鈕 ＋ 伺服，再逐步加紅綠燈與蜂鳴器

### 📖 情境

購物中心停車場出口的柵欄，收費員按一下按鈕，柵欄緩緩升起。柵欄旁要有紅綠燈告訴駕駛能不能通過，升降時蜂鳴器發出提示音，提醒行人注意。

### 🎯 本關配線學習目標

- 第一次接伺服：三色線、用測試器找角度
- 用「兩燈共腳」做出柵欄兩側同步的燈號

### 🃏 ① 客戶限制卡

| 限制卡 | 現場條件 |
| --- | --- |
| **A** | 收費員**按一下升起、再按一下放下**（手動） |
| **B** | 收費員按一下升起，**3 秒後自動放下**；Pin 2～4 已被收費機佔用 |
| **C** | 手動升降；柵欄**兩側（入口、出口方向）各一組紅綠燈**，但只能用 **2 隻腳**控制 4 顆燈；蜂鳴器必須接 **A3** |

### ✏️ ② 接線前決策題

1. 伺服需要電阻嗎？需要 `~` 腳嗎？本關一共要幾顆 220Ω、幾顆 10kΩ？（限制卡 C 要特別算）
2. 紅綠燈只需要亮或滅，需要 `~` 腳嗎？
3. 限制卡 B：「3 秒後自動放下」要改哪個參數？
4. 限制卡 C：4 顆燈只用 2 隻腳，怎麼接？

**腳位規劃表**：

| 元件 | 腳位 |
| --- | --- |
| 柵欄伺服（橘線） | |
| 收費員按鈕 | |
| 紅燈（限制卡 C：兩顆共用） | |
| 綠燈（限制卡 C：兩顆共用） | |
| 蜂鳴器 | |

### 🔌 ③ 接線任務

**Step 1：按鈕＋伺服**

1. 伺服的紅線接 5V 軌、棕線接 GND 軌、橘線接你規劃的腳位。
2. 按鈕接法同前。
3. ✅ 檢查：**工具 1**，填好角度記錄表（柵欄「水平放下」和「垂直升起」各是幾度？）。

**Step 2：紅綠燈**

1. 紅燈、綠燈放在伺服旁邊，各串 220Ω。
2. 限制卡 C：另一組紅綠燈放在麵包板另一端，紅燈接同一隻「紅燈腳」、綠燈接同一隻「綠燈腳」，每顆各串 220Ω。
3. ✅ 檢查：**工具 2**。

**Step 3：蜂鳴器**

1. 接好蜂鳴器。
2. ✅ 檢查：蜂鳴器測試器。

### 💻 ④ 套用程式模板 T13

```cpp
// ===== 程式模板 T13：按鈕控制柵欄 =====
#include <Servo.h>

// ----- 腳位區（沒接的元件填 -1）-----
int pinServo  = ?;                  // 柵欄伺服
int pinButton = ?;                  // 按鈕
int ledRed    = ?;                  // 紅燈（柵欄關閉時亮）
int ledGreen  = ?;                  // 綠燈（柵欄開啟時亮）
int pinBuzzer = ?;                  // 提示蜂鳴器

// ----- 參數區 -----
int closedAngle = 0;                // 關閉角度（依角度記錄表）
int openAngle   = 90;               // 開啟角度（依角度記錄表）
int sweepDelay  = 10;               // 每轉 1 度等幾毫秒（越大越慢）
int autoClose   = 0;                // 0：手動（按一下開、再按一下關）；大於 0：開啟後幾毫秒自動關閉
int openTone    = 1200;             // 開啟提示音
int closeTone   = 600;              // 關閉提示音
String gateName = "Gate";           // 顯示名稱（英文）

// ----- 功能開關 -----
bool useLights = false;             // Step 2：紅綠燈
bool useBuzzer = false;             // Step 3：蜂鳴器

// ===== 以下不用改 =====
Servo gate;
bool isOpen = false;
int lastButton = LOW, count = 0;

void sweepTo(int from, int to) {
  int step = (to > from) ? 1 : -1;
  for (int a = from; a != to; a += step) { gate.write(a); delay(sweepDelay); }
  gate.write(to);
}

void showLights(bool open) {
  if (!useLights) return;
  if (ledRed >= 0)   digitalWrite(ledRed,   open ? LOW : HIGH);
  if (ledGreen >= 0) digitalWrite(ledGreen, open ? HIGH : LOW);
}

void openGate() {
  if (useBuzzer) tone(pinBuzzer, openTone, 300);
  sweepTo(closedAngle, openAngle);
  isOpen = true;
  count++;
  showLights(true);
  Serial.print(gateName + " OPEN  #");
  Serial.println(count);
}

void closeGate() {
  showLights(false);                // 放下前先轉紅燈
  if (useBuzzer) tone(pinBuzzer, closeTone, 300);
  sweepTo(openAngle, closedAngle);
  isOpen = false;
  Serial.println(gateName + " CLOSED");
}

void setup() {
  gate.attach(pinServo);
  gate.write(closedAngle);
  pinMode(pinButton, INPUT);
  if (useLights) {
    if (ledRed >= 0)   pinMode(ledRed, OUTPUT);
    if (ledGreen >= 0) pinMode(ledGreen, OUTPUT);
  }
  showLights(false);
  Serial.begin(9600);
}

void loop() {
  int now = digitalRead(pinButton);
  if (now == HIGH && lastButton == LOW) {
    delay(50);
    if (autoClose > 0) {
      openGate();
      delay(autoClose);
      closeGate();
    } else if (isOpen) {
      closeGate();
    } else {
      openGate();
    }
  }
  lastButton = now;
}
```

**本關要改的地方**：

| 區塊 | 要做什麼 |
| --- | --- |
| 腳位區 | 依腳位規劃表填入；限制卡 C 的蜂鳴器寫 `A3` |
| 參數區 | `closedAngle`、`openAngle` 依角度記錄表；限制卡 B 的 `autoClose` 改成 `3000` |
| 功能開關 | Step 2 → `useLights = true`；Step 3 → `useBuzzer = true` |

### 🔄 ⑤ 配線變化挑戰（程式一個字都不能改）

| 客戶臨時要求 | 你要改哪幾條線？ |
| --- | --- |
| 「出口對面的保全亭也要看到紅綠燈」——再加一組紅綠燈（限制卡 C 的同學：改成拿掉一組） | |
| 「紅燈和綠燈裝反了：柵欄開著時亮紅燈」——老師會動手腳，找出來並修好 | |

### 💼 情境思考

1. 程式裡「放下前先轉紅燈」這個小細節，是為了避免什麼危險？

⭐⭐ **難度**：感測器 ＋ 伺服 ＋ 光敏電阻 ＋ RGB（注意伺服借走 9、10）

// ===== 程式模板 T14：感測比例開合 =====
#include <Servo.h>

// ----- 腳位區（沒接的元件填 -1）-----
int pinSensor = A0;                 // 主感測器
int pinLDR    = A1;                 // 夜間偵測光敏電阻
int pinServo  = ?;                  // 伺服
int pinR = ?, pinG = ?, pinB = ?;   // 狀態 RGB

// ----- 參數區 -----
int sensorType = 1;                 // 0：旋鈕或光敏電阻（0~1023）；1：TMP36（°C）
int inMin = 20, inMax = 35;         // 感測值範圍
int angleMin = 0, angleMax = 90;    // 對應的角度（可以大的寫前面＝反向）
bool closeAtNight = true;           // 夜間強制回到 angleMin（或 nightAngle）
int nightAngle = 0;                 // 夜間角度
int darkLine = 300;                 // 光線低於這個數字算夜間
int colorLow[3]  = { 0, 0, 255 };   // 角度接近較小的那一端（藍）
int colorMid[3]  = { 255, 140, 0 }; // 中間（琥珀）
int colorHigh[3] = { 0, 255, 0 };   // 角度接近較大的那一端（綠）
String deviceName = "Window";       // 顯示名稱

// ----- 功能開關 -----
bool useNight = false;              // Step 2：夜間光敏電阻
bool useRGB   = false;              // Step 3：狀態 RGB

// ===== 以下不用改 =====
Servo arm;

float readValue() {
  int raw = analogRead(pinSensor);
  if (sensorType == 1) return (raw * 5.0 / 1023.0 - 0.5) * 100.0;
  return raw;
}

void setColor(int c[]) {
  analogWrite(pinR, c[0]);
  analogWrite(pinG, c[1]);
  analogWrite(pinB, c[2]);
}

void setup() {
  arm.attach(pinServo);
  if (useRGB) { pinMode(pinR, OUTPUT); pinMode(pinG, OUTPUT); pinMode(pinB, OUTPUT); }
  Serial.begin(9600);
}

void loop() {
  float v = readValue();
  float vc = constrain(v, min(inMin, inMax), max(inMin, inMax));
  int angle = map((int)vc, inMin, inMax, angleMin, angleMax);

  bool night = useNight && closeAtNight && (analogRead(pinLDR) < darkLine);
  if (night) angle = nightAngle;
  arm.write(angle);

  if (useRGB) {
    int lo = min(angleMin, angleMax), hi = max(angleMin, angleMax);
    if (angle <= lo + 2)      setColor(colorLow);
    else if (angle >= hi - 2) setColor(colorHigh);
    else                      setColor(colorMid);
  }

  Serial.print("Sensor: ");
  Serial.print(v);
  Serial.print("   " + deviceName + ": ");
  Serial.print(angle);
  Serial.println(night ? " deg (NIGHT)" : " deg");
  delay(300);
}
```

| --- | --- |
| 腳位區 | 依腳位規劃表填入 |
| 參數區 | 依感測與角度規格表修改；`angleMin`、`angleMax` 參考角度記錄表 |
| 功能開關 | Step 2 → `useNight = true`（限制卡 B 不開）；Step 3 → `useRGB = true` |

// ===== 程式模板 T15：光柵自動門＋人數管制 =====
#include <Servo.h>

// ----- 腳位區（沒接的元件填 -1）-----
int pinLDR    = A0;                 // 入口光柵
int pinServo  = ?;                  // 自動門伺服
int pinBuzzer = ?;                  // 蜂鳴器
int pinExit   = ?;                  // 離場鈕
int pinR = ?, pinG = ?, pinB = ?;   // 入口狀態燈

// ----- 參數區 -----
int threshold = 300;                // 光柵門檻（依記錄表）
bool triggerWhenDark = true;        // true：被擋住（變暗）觸發；false：變亮觸發
int capacity  = 5;                  // 人數上限
int holdTime  = 3000;               // 開門停留時間（毫秒）
int closedAngle = 0, openAngle = 90;   // 依角度記錄表
int sweepDelay = 8;                 // 每轉 1 度等幾毫秒
int welcomeTone = 1200;             // 歡迎音
int refuseTone  = 300;              // 拒絕音
int colorOK[3]   = { 0, 255, 0 };   // 可入場（綠）
int colorFull[3] = { 255, 0, 0 };   // 客滿（紅）
String placeName = "Gallery";

// ----- 功能開關 -----
bool useCapacity = false;           // Step 2：人數管制＋蜂鳴器
bool useExit     = false;           // Step 3：離場鈕＋入口燈

// ===== 以下不用改 =====
Servo door;
bool wasTrig = false;
int inside = 0, lastExit = LOW;

void sweepTo(int from, int to) {
  int step = (to > from) ? 1 : -1;
  for (int a = from; a != to; a += step) { door.write(a); delay(sweepDelay); }
  door.write(to);
}

void setColor(int c[]) {
  analogWrite(pinR, c[0]);
  analogWrite(pinG, c[1]);
  analogWrite(pinB, c[2]);
}

void setup() {
  door.attach(pinServo);
  door.write(closedAngle);
  if (useExit) {
    pinMode(pinExit, INPUT);
    pinMode(pinR, OUTPUT); pinMode(pinG, OUTPUT); pinMode(pinB, OUTPUT);
  }
  Serial.begin(9600);
}

void loop() {
  if (useExit) {
    int now = digitalRead(pinExit);
    if (now == HIGH && lastExit == LOW) {
      delay(50);
      if (inside > 0) inside--;
      Serial.print("Visitor left. Inside: ");
      Serial.println(inside);
    }
    lastExit = now;
    setColor(inside >= capacity ? colorFull : colorOK);
  }

  int light = analogRead(pinLDR);
  bool trig = triggerWhenDark ? (light < threshold) : (light > threshold);
  if (trig && !wasTrig) {
    if (useCapacity && inside >= capacity) {
      Serial.println(placeName + " FULL - entry refused");
      tone(pinBuzzer, refuseTone, 600);
    } else {
      if (useCapacity) {
        inside++;
        tone(pinBuzzer, welcomeTone, 100);
        Serial.print("Welcome! Inside: ");
        Serial.println(inside);
      }
      sweepTo(closedAngle, openAngle);
      delay(holdTime);
      sweepTo(openAngle, closedAngle);
    }
  }
  wasTrig = trig;
  delay(30);
}
```

## 關卡 4：物流包裹分揀站（模板 T16）

⭐⭐⭐⭐ **難度**：**2 顆伺服** ＋ 光柵 ＋ 旋鈕 ＋ 3 顆燈 ＋ 蜂鳴器 ＋ 急停鈕 ＋ RGB

### 📖 情境

物流中心的輸送帶末端要自動分揀包裹。包裹經過光柵時，系統讀取一個數值（用旋鈕模擬磅秤或尺寸量測），依數值推入三條分流道之一：小的由擋板 A（伺服 A）推出、大的由擋板 B（伺服 B）推出、中間的直接通過。每條分流道有一顆燈，分到哪一道就閃一下。現場有一顆**急停鈕**：按下後擋板歸位、系統停止、狀態燈轉紅；再按一次恢復。

### 🎯 本關配線學習目標

- 兩顆伺服各接一條訊號線、共用電源軌
- 用改線改變「哪一顆擋板負責哪一道」

### 🃏 ① 客戶限制卡

| 限制卡 | 分流依據 | 現場條件 |
| --- | --- | --- |
| **A** | **重量** 0～30 kg：10 kg 以下走輕件道、20 kg 以上走重件道 | 無 |
| **B** | **尺寸** 0～60 cm：20 cm 以下走小件道、40 cm 以上走大件道 | 分流道燈**由右往左**排列（小件道在最右） |
| **C** | **重量** 0～30 kg（同 A） | Pin 2 已被輸送帶控制器佔用；急停鈕必須接 **A3**；蜂鳴器接 **Pin 3** |

### ✏️ ② 接線前決策題

1. 兩顆伺服的紅、棕線要怎麼接？橘線可以共用嗎？為什麼這一關不行？
2. 本關有伺服又有蜂鳴器，狀態 RGB 只用綠、紅，需要 `~` 腳嗎？
3. 一般腳位總共要幾隻？Pin 2～13 夠嗎？（限制卡 C 扣掉 Pin 2）

1. 光敏電阻（配 10kΩ）和旋鈕放在麵包板左側（輸送帶入口）。
2. 擋板 A 伺服放在中間偏左；3 顆分流道燈放在右側。

### 💻 ④ 套用程式模板 T16

```cpp
// ===== 程式模板 T16：雙伺服分揀＋急停 =====
#include <Servo.h>

// ----- 腳位區（沒接的元件填 -1）-----
int pinLDR    = A0;                 // 包裹光柵
int pinKnob   = A1;                 // 量測旋鈕（模擬磅秤或尺寸）
int pinArmA   = ?;                  // 擋板 A 伺服（第 1 道）
int pinArmB   = ?;                  // 擋板 B 伺服（第 3 道）
int lane[3]   = { ?, ?, ? };        // 第 1、2、3 道的燈
int pinBuzzer = ?;                  // 蜂鳴器
int pinStop   = ?;                  // 急停鈕
int pinR = ?, pinG = ?, pinB = ?;   // 狀態 RGB

// ----- 參數區 -----
int threshold = 300;                // 光柵門檻
String unit = "kg";                 // 量測單位
int valueMin = 0, valueMax = 30;    // 量測範圍
int lowLimit  = 10;                 // 小於這個值 → 第 1 道
int highLimit = 20;                 // 大於等於這個值 → 第 3 道
String laneName[3] = { "Light", "Normal", "Heavy" };
int restAngle = 0, pushAngle = 70;  // 擋板平常角度、推出角度
int pushTime  = 800;                // 推出停留時間
int colorRun[3]  = { 0, 255, 0 };   // 運轉（綠）
int colorStop[3] = { 255, 0, 0 };   // 急停（紅）

// ----- 功能開關 -----
bool useArmB = false;               // Step 2：擋板 B＋蜂鳴器
bool useStop = false;               // Step 3：急停＋RGB

// ===== 以下不用改 =====
Servo armA, armB;
bool wasTrig = false, stopped = false;
int lastStop = LOW;
int count[3] = { 0, 0, 0 };

void setColor(int c[]) {
  analogWrite(pinR, c[0]);
  analogWrite(pinG, c[1]);
  analogWrite(pinB, c[2]);
}

void setup() {
  armA.attach(pinArmA);
  armA.write(restAngle);
  if (useArmB) { armB.attach(pinArmB); armB.write(restAngle); }
  for (int i = 0; i < 3; i++) pinMode(lane[i], OUTPUT);
  if (useStop) {
    pinMode(pinStop, INPUT);
    pinMode(pinR, OUTPUT); pinMode(pinG, OUTPUT); pinMode(pinB, OUTPUT);
  }
  Serial.begin(9600);
}

void loop() {
  if (useStop) {
    int now = digitalRead(pinStop);
    if (now == HIGH && lastStop == LOW) {
      delay(50);
      stopped = !stopped;
      if (stopped) {
        armA.write(restAngle);
        if (useArmB) armB.write(restAngle);
        if (useArmB) tone(pinBuzzer, 400, 500);
        Serial.println("!!! EMERGENCY STOP !!!");
      } else {
        Serial.println("System resumed");
      }
    }
    lastStop = now;
    if (stopped) { setColor(colorStop); delay(30); return; }   // 安全連鎖：後面全部不執行
    setColor(colorRun);
  }

  bool trig = analogRead(pinLDR) < threshold;
  if (trig && !wasTrig) {
    int v = map(analogRead(pinKnob), 0, 1023, valueMin, valueMax);
    int target = 1;
    if (v < lowLimit) target = 0;
    else if (v >= highLimit && useArmB) target = 2;

    if (target == 0) armA.write(pushAngle);
    if (target == 2) armB.write(pushAngle);
    digitalWrite(lane[target], HIGH);
    if (useArmB) tone(pinBuzzer, 1500, 80);
    delay(pushTime);
    digitalWrite(lane[target], LOW);
    armA.write(restAngle);
    if (useArmB) armB.write(restAngle);

    count[target]++;
    Serial.print(v);
    Serial.print(" " + unit + " -> " + laneName[target]);
    Serial.print("   [");
    for (int i = 0; i < 3; i++) { Serial.print(laneName[i] + ":"); Serial.print(count[i]); Serial.print(" "); }
    Serial.println("]");
  }
  wasTrig = trig;
  delay(30);
}
```

| --- | --- |
| 腳位區 | 依腳位規劃表填入（限制卡 B 注意分流道燈順序；限制卡 C 急停鈕寫 `A3`） |
| 參數區 | 依分揀規格表修改 `unit`、`valueMin`、`valueMax`、`lowLimit`、`highLimit`、`laneName[]`；角度依記錄表 |

## 配線除錯站

| 現象 | 先檢查這裡 | 修正方式 |
| --- | --- | --- |
| 伺服完全不動 | 橘線是否接到程式裡的腳位；紅線 5V、棕線 GND | 用工具 1 測試 |

## 📖 本週詞彙表

| 名稱 | 白話解釋 |
| --- | --- |
| 伺服馬達（Servo） | 能轉到 0～180° 指定角度並停住的馬達，三條線、不用電阻 |
| 角度記錄表 | 用伺服測試器找出每顆伺服「開／關」角度的紀錄 |
| 平滑轉動 | 一度一度慢慢轉到目標角度 |
| 共用訊號線 | 兩顆伺服的橘線接同一隻腳，同步轉動 |
| ~ 腳可用表 | 伺服借走 9、10，蜂鳴器借走 3、11 的調光功能 |
| 安全連鎖（Interlock） | 不安全的條件成立時，強制禁止設備動作 |
| 急停（Emergency Stop） | 一按就讓所有動作停止、回到安全狀態的按鈕 |
| 容量管制 | 依人數或數量上限決定是否允許進入 |

## 反思與延伸討論

1. 本週的系統第一次「會動」。和只會亮燈、出聲的系統相比，設計時多了哪些必須考慮的風險？請從**人員安全、設備損壞、物品損失**三個角度各舉一例。
2. 伺服的方向不能靠改線反轉，只能改參數；旋鈕、光敏電阻則可以靠改線。這告訴你「硬體」和「軟體」各自的彈性在哪裡？
3. 本週「伺服＋蜂鳴器」讓 `~` 腳只剩 5、6。在真實產品開發中，「元件之間互相搶資源」很常見。遇到這種限制時，除了犧牲功能，還有哪些解法？
