# 物聯網應用實作課程：16 週 Arduino × Tinkercad 教學設計
### 密室逃脫主題式專案 — 為工業管理系學生設計的漸進式課程

---

## 課程理念

本課程專為**已具備電阻、串並聯電路基礎，但無電子電路深入經驗**的工業管理系學生設計，核心原則如下：

| 原則 | 說明 |
|---|---|
| **主題式專案導向** | 全學期以「密室逃脫機關設計師」情境貫穿，每週一個好玩主題，維持學習動機 |
| **緩坡堆疊** | 每週只新增 1～3 個新元件或觀念，透過大量範例與練習題逐步累積能力 |
| **模擬優先** | 全程使用 [Tinkercad Circuits](https://www.tinkercad.com/) 線上模擬，所有元件均已於平台驗證可用，且全程只使用 Arduino Uno 一張主板 |
| **系統思維培養** | 從期中週開始反覆強化「模組化架構、優先權排序、安全連鎖」等系統設計素養 |
| **終局整合** | 最後兩週不學新元件，收斂成一套完整、可展演的期末畢業作品 |

**內容規模**：每週教材最低 800 行，包含完整電路配置指引、故事情境、詳實註解程式碼、分級練習題、額外主題卡與詞彙表。

## 📚 課程目錄

### 第一階段：數位基礎與邏輯建立（第 1～4 週）
> 目標：複習電阻與串並聯基礎，銜接純文字程式邏輯——變數、迴圈、陣列、條件判斷

- [第 1 週：密室逃脫的第一道機關](./weeks/week-01.md) — LED 陣列、`for` 迴圈、自訂函式
- [第 2 週：搶答對決](./weeks/week-02.md) — 按鈕、防彈跳、狀態變數、AND/OR 邏輯
- [第 3 週：迪斯可派對燈光秀](./weeks/week-03.md) — PWM、RGB LED 混色、二維陣列
- [第 4 週：格鬥搖桿與加速旋鈕](./weeks/week-04.md) — 類比輸入、`map()`、`constrain()`

### 第二階段：感測與動力輸出（第 5～8 週）
> 目標：引入聲音、光線、溫度感測與伺服馬達，建立自動化系統思維

- [第 5 週：密室音效與雷射防盜網](./weeks/week-05.md) — 蜂鳴器、光敏電阻、狀態轉變偵測
- [第 6 週：智慧溫控保險庫](./weeks/week-06.md) — TMP36、`float`、警報鎖定與人工復歸
- [第 7 週：機械保全閘門](./weeks/week-07.md) — 伺服馬達、物件導向雛形、安全連鎖
- [第 8 週：期中專題 — 智慧密室綜合監控站](./weeks/week-08.md) — 系統架構設計、模組化、QA 測試

### 第三階段：工業物聯網基礎元件（第 9～12 週）
> 目標：處理更複雜的通訊介面與動力驅動，直接對應真實工業自動化元件

- [第 9 週：停車場雷達](./weeks/week-09.md) — HC-SR04 超音波測距、`pulseIn()`
- [第 10 週：智慧輸送帶](./weeks/week-10.md) — DC Motor、L293D 驅動晶片、緩啟停
- [第 11 週：產線戰情看板](./weeks/week-11.md) — LCD 16x2、畫面優化、自訂字元
- [第 12 週：金庫密碼鎖與期末統整](./weeks/week-12.md) — 矩陣鍵盤、字串處理、Arduino 單元總驗收

### 第四階段：進階整合與終極大專題（第 13～16 週）
> 目標：補齊工業自動化關鍵元件，並將整學期所學收斂成完整畢業作品

- [第 13 週：產線數字看板升級站](./weeks/week-13.md) — 74HC595 位移暫存器、七段顯示器、位元運算
- [第 14 週：智慧感應與操作台](./weeks/week-14.md) — 繼電器、PIR 感測器、搖桿、手動優先權
- [第 15 週：終極整合大專題（上）](./weeks/week-15.md) — 系統設計、子系統開發、三套專題藍圖
- [第 16 週：終極整合大專題（下）](./weeks/week-16.md) — `millis()` 狀態機重構、壓力測試、期末展演

## 🔧 全學期使用元件（皆已確認 Tinkercad 可用）

LED、220Ω/10kΩ 電阻、RGB LED、Pushbutton、Potentiometer、Buzzer、Photoresistor、TMP36、Micro Servo、Ultrasonic Distance Sensor（HC-SR04）、DC Motor、L293D、LCD 16x2、4x4 Membrane Keypad、74HC595 位移暫存器、7-Segment Display、Relay Module、PIR Motion Sensor、Joystick

**全程僅使用 Arduino Uno R3 一張主板**，詳細接線請參閱[附錄 A](./appendix/appendix-a-wiring.md)。

## 如何使用本文件

1. 每週開頭列出**學習目標**、**電路體檢站**（快速複習前置知識，不重複教學）、**模擬設計專案配置**（Tinkercad 接線指引）。
2. 每個關卡附上**情境故事**與**完整註解程式碼**，註解採「工業邏輯語言」而非單純「腳位語言」，強化工管系的流程思維。
3. 每週皆有 **5 道關卡 + 1 個 BOSS 整合關**，並附上「常見錯誤除錯站」對照表。
4. 每週最後附上 **15 題分級練習題**（基礎/中等/挑戰）、**額外主題卡**（開放式專案）、**詞彙表**、**反思討論**與**檢核清單**。
5. 每個檔案內都有「上一週 / 下一週 / 回目錄」導覽連結，方便在 GitHub 上瀏覽切換。
