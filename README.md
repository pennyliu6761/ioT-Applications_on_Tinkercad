# 物聯網應用實作課程：16 週 Arduino × Tinkercad 教學設計
### 情境思考 × 電路配置導向 — 為工業管理系學生設計的漸進式課程

---

## 課程理念

本課程專為**沒有電子電路背景的工業管理系學生**設計。我們不把學生訓練成工程師，而是培養能**讀懂現場需求、規劃系統配置、和工程師溝通**的管理人才。

| 原則 | 說明 |
|---|---|
| **情境優先，不是程式優先** | 從第 4 週起，學生扮演「物聯網顧問公司」的顧問，每週承接真實場域的委託案（工廠、物流、零售、醫療、辦公室、社區） |
| **電路配置是主角** | 每個關卡的第一步都是「接線前決策題＋腳位規劃」；程式以**模板 T1～T40** 提供，學生只改腳位區、參數區與功能開關 |
| **同一關卡、不同配線** | 每個關卡依座號抽**客戶限制卡**（A／B／C），同一個情境配出不同電路，避免複製貼上；最後還有「程式不改、只改線」的**配線變化挑戰** |
| **循序漸進的複雜度** | 每個關卡分 Step 1 → 2 → 3，每一步多接幾個元件、打開一個「功能開關」；每週練習題從 Lv.1 到 Lv.6 逐步加難 |
| **每週多元成果** | 每週完成 **4 個關卡**（各自一個 Tinkercad 檔案，同學互相驗收簽名），加上 6 關情境練習題 |
| **管理思維貫穿** | 每個專案都附 💼 管理面向思考題：看板管理、安燈、節拍時間、稼動率、失效安全、SOP、成本效益…… |
| **模擬優先** | 全程使用 [Tinkercad Circuits](https://www.tinkercad.com/) 線上模擬，只使用 Arduino Uno 一張主板 |
| **兩次整合專題** | 第 8 週期中、第 15～16 週期末，以顧問身分完成「需求分析 → 規劃 → 建置 → 驗收 → 提案」完整流程 |

## 📚 課程目錄

### 第一階段：數位基礎與邏輯建立（第 1～4 週）
> 目標：熟悉 LED、按鈕、RGB、旋鈕的接法，建立「每條燈線一顆電阻」「要調光才接 `~` 腳」等基本配線判斷

| 週次 | 主題 | 新元件 | 配線與管理重點 |
|---|---|---|---|
| [第 1 週](./weeks/week-01.md) | 密室逃脫的第一道機關 | LED、220Ω | LED 陣列、限流電阻 |
| [第 2 週](./weeks/week-02.md) | 搶答對決 | 按鈕、10kΩ | 下拉電阻、狀態變數、AND／OR |
| [第 3 週](./weeks/week-03.md) | 迪斯可派對燈光秀 | RGB LED | `~` 腳與 PWM、RGB 混色；情境配置挑戰（營業招牌、安燈、取餐叫號） |
| [第 4 週](./weeks/week-04.md) | 旋鈕控制的智慧場域 | 旋鈕 | A 腳、`map()` 換算、借用 A 腳；會議室照明、產線輸送帶、倉庫庫存看板、手搖飲點餐面板 |

### 第二階段：感測、警報與動作（第 5～8 週）
> 目標：讓系統能「自己感覺環境」並「出聲提醒、動手處理」，建立警報處理與安全連鎖觀念

| 週次 | 主題 | 新元件 | 配線與管理重點 |
|---|---|---|---|
| [第 5 週](./weeks/week-05.md) | 會發聲、會看光的智慧場域 | 蜂鳴器、光敏電阻 | 蜂鳴器借走 3、11；感測器擺放位置；診所叫號、智慧路燈、防盜光柵、產線計數 |
| [第 6 週](./weeks/week-06.md) | 溫度監控的智慧場域 | TMP36 | 有方向性的元件；三種警報處理（自動恢復／靜音／鎖定）；冷藏櫃、溫室、機房、冷鏈貨車 |
| [第 7 週](./weeks/week-07.md) | 會動的智慧場域 | 伺服馬達 | 伺服借走 9、10（「~ 腳可用表」）；安全連鎖、急停；停車柵欄、溫室天窗、展場自動門、包裹分揀 |
| [第 8 週](./weeks/week-08.md) | **期中專題 — 智慧場域整合提案** | （無新元件） | 需求分析、規格訂定、腳位規劃、模組化、優先權、QA 驗收、客戶提案簡報 |

### 第三階段：進階感測、動力與人機介面（第 9～12 週）
> 目標：處理距離感測、持續運轉的馬達、文字看板與鍵盤輸入，學會各種「省腳位」技巧

| 週次 | 主題 | 新元件 | 配線與管理重點 |
|---|---|---|---|
| [第 9 週](./weeks/week-09.md) | 會量距離的智慧場域 | 超音波 HC-SR04 | 安裝位置換算、多顆輪流量測；給皂機、倒車引導、智慧垃圾桶、停車場入口 |
| [第 10 週](./weeks/week-10.md) | 會持續運轉的智慧場域 | 直流馬達、L293D | L293D 四種接法（依需求省腳位）、緩啟動；抽風扇、鐵捲門、輸送帶、AGV 無人搬運車 |
| [第 11 週](./weeks/week-11.md) | 會說話的智慧場域 | LCD 16×2（平行版、I2C 版） | 依腳位選 LCD 版本；看板設計原則、稼動率；狀態牌、溫度看板、產線績效看板、戰情中心 |
| [第 12 週](./weeks/week-12.md) | 會輸入的智慧場域＋Arduino 單元總整理 | 4×4 矩陣鍵盤 | 鍵盤只接 3 行、操作流程設計、防呆；打卡機、販賣機、密碼門鎖、品管抽檢站；**全元件配線速查表、配線技巧總整理、模板索引 T1～T32** |

### 第四階段：擴充、控制與期末整合（第 13～16 週）
> 目標：用位移暫存器突破腳位限制、用繼電器控制大型設備、建立自動／手動模式觀念，最後完成期末顧問專案

| 週次 | 主題 | 新元件 | 配線與管理重點 |
|---|---|---|---|
| [第 13 週](./weeks/week-13.md) | 用 3 隻腳點亮整面看板 | 74HC595、七段顯示器 | 位移暫存器串接、一個輸出接兩顆燈、按鈕並聯；招牌燈效、行人號誌、產量計數器、安燈總看板 |
| [第 14 週](./weeks/week-14.md) | 自動與手動的智慧場域 | 繼電器、PIR、類比搖桿 | NO／NC 與失效安全、一顆繼電器帶兩個相反負載、HOA 三段模式；感應燈、空調節能、天車、輸送線控制盤 |
| [第 15 週](./weeks/week-15.md) | **期末整合大專題（上）** | （無新元件） | 小組客戶限制卡；兩個完整範例（冷鏈出貨中心、便利商店，跟做限制卡）；規劃書、子系統套用模板建置 |
| [第 16 週](./weeks/week-16.md) | **期末整合大專題（下）** | （無新元件） | 系統整合、現場配線變化挑戰、QA 驗收與同儕交叉測試、成本效益分析、客戶提案展演、學期總回顧 |

## 如何使用本教材

### 一般週次（第 4～7、9～14 週）的結構

| 區塊 | 內容 |
|---|---|
| **開場任務簡報** | 本週四個客戶委託案、套用模板與難度 |
| **認識新元件** | 白話說明、接法表、在 Tinkercad 的操作方式 |
| **本週配線新技巧** | 「改線就能解決」的技巧（共腳、反相、共用訊號線、並聯、NO＋NC……） |
| **配線口訣卡** | 本週配線規則，累積前幾週的口訣 |
| **共用工具** | 接線驗證器、各元件測試器與記錄表——接線後先檢查，再上傳正式程式 |
| **四個關卡（五個固定環節）** | 🃏 客戶限制卡 → ✏️ 接線前決策題 → 🔌 接線任務 Step 1～3 → 💻 套用程式模板 → 🔄 配線變化挑戰 → ✅ 同學驗收簽名 |
| **練習題大補帖 Lv.1～Lv.6** | 新情境套用本週模板，填參數修改表；Lv.3 起附配線設計單；Lv.6 為顧問提案 |
| **配線除錯站** | 「現象 → 先檢查這裡 → 修正方式」對照表 |
| **成果繳交與評分** | 繳交清單、評分比重建議、3 節課的時間安排 |
| **詞彙表、反思討論、檢核清單** | 每週收尾 |

### 程式碼的使用方式

學生**不需要從頭寫程式**。每個程式模板（T1～T40）最上方都有三個區塊：

```cpp
// ----- 腳位區（沒接的填 -1）-----
int pinLight = ?;        // ← 填入你接的腳位
// ----- 參數區 -----
int darkLine = 300;      // ← 依情境、限制卡調整
// ----- 功能開關 -----
bool useRGB  = false;    // ← Step 2 接好後改成 true
```

- `?` 填入學生自己規劃的腳位；沒接的元件填 `-1`
- 溫度線、距離、角度、顏色、NO／NC 等規格，在參數區依情境與限制卡調整
- 功能開關 `false` → `true`，對應每個 Step 接好的元件
- 模板索引見第 12 週「Arduino 單元總整理」（T1～T32），T33～T40 在第 13、14 週

### 整合專題週次（第 8、15、16 週）

以**里程碑**推進，對應真實顧問專案流程：

| 期中（第 8 週） | 期末（第 15～16 週） |
|---|---|
| 小組客戶限制卡（4 張） | 小組客戶限制卡（甲～丁）＋範例跟做限制卡 |
| M0 需求分析與規劃書 | F0 選題、F1 規劃書（九項） |
| M1～M3 三個功能模組 | F2 子系統建置（至少 3 個） |
| M4 系統整合與優先權＋現場配線變化 | F3 系統整合（五步驟、版本管理）＋F3.5 現場配線變化挑戰 |
| M5 驗收測試（QA） | F4 驗收測試（六類測試、缺陷分級、交叉測試） |
| M6 提案簡報 | F5 客戶提案展演（含成本效益分析） |

### 給教師的建議

- 每週第 1 節建議**全班一起接一次新元件並跑測試器**，確認每個人都接對，再開始關卡
- 配線變化挑戰中標示「老師會動手腳」的題目，請老師在驗收時偷偷改一兩條線，讓學生從現象反推接線
- 練習題 Lv.1～Lv.2 適合課堂暖身，Lv.3～Lv.4 適合課後作業，Lv.5 選做加分，Lv.6 可分組
- 各週文件中「上課前請先在 Tinkercad 確認」的提醒，是依元件規格撰寫、尚未實際在 Tinkercad 逐一驗證的項目（例如元件腳位名稱、模擬操作方式），建議備課時先試接一次
