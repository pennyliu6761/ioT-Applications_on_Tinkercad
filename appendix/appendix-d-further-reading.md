# 附錄 D：延伸閱讀與課程總結

## 延伸學習方向

| 主題 | 銜接方向 |
|---|---|
| Wi-Fi 連網（ESP32 / Arduino IoT Cloud） | 讓終極密室系統的資料能上傳雲端，實現遠端監控儀表板 |
| EEPROM 資料持久化 | 斷電後仍能保存歷史記錄（如第 16 週延伸挑戰 A 提到的最佳完成時間） |
| I2C / 序列埠通訊協定 | 多台 Arduino 之間協同運作（如第 16 週延伸挑戰 C 提到的多間密室聯動） |
| PLC 可程式化邏輯控制器 | 這學期學到的優先權設計、狀態機、安全連鎖等概念，在真實工業 PLC 程式設計中有高度對應的實務做法 |
| mBot2 / 機器人學（社團選修） | 若學校或社團有意願，可延續本課程的感測、控制、狀態機概念，銜接機器人避障、循跡等應用 |

## 課程設計理念回顧

本課程專為**已具備電阻、串並聯電路基礎，但無電子電路深入經驗的工業管理系學生**設計，核心原則包括：

1. **主題式專案導向**：每週一個密室逃脫主題機關，貫穿全學期的敘事線，提升學習動機。
2. **緩坡堆疊**：每週僅新增 1～3 個新元件或觀念，透過大量範例與練習題逐步累積能力。
3. **模擬優先**：全程使用 Tinkercad Circuits 模擬平台，降低硬體成本與接線挫折感，同時確保每個使用的元件都已於平台驗證可用。
4. **系統思維培養**：從第 8 週開始反覆強化「模組化架構、優先權排序、安全連鎖」等系統設計素養，這是工業管理系學生未來銜接智慧製造、自動化領域最重要的軟實力。
5. **終局整合**：最後兩週不學新元件，而是把整學期所學收斂成一套完整、可展演的畢業作品，讓學習成果具體可見。

## 16 週課程地圖總覽

```
第一階段：數位基礎與邏輯建立（1~4週）
  LED → 按鈕 → RGB混色 → 旋鈕/map()

第二階段：感測與動力輸出（5~8週）
  蜂鳴器/光敏 → 溫度/警報鎖定 → 伺服馬達 → 期中整合

第三階段：工業物聯網基礎元件（9~12週）
  超音波 → 直流馬達/L293D → LCD → 矩陣鍵盤/期末統整

第四階段：進階整合與終極專題（13~16週）
  位移暫存器/七段顯示 → 繼電器/PIR/搖桿 → 終極專題(上) → 終極專題(下)
```

## 版本資訊

- **課程文件版本**：v2.0（Tinkercad 全程版，不含 mBot2）
- **設計對象**：工業管理系（已具備電阻與串並聯基礎）
- **教學平台**：Tinkercad Circuits
- **程式語言**：Arduino C/C++（純文字模式）
- **總週數**：16 週（每週最低 800 行教材內容）
- **使用主板**：全程僅使用 Arduino Uno R3

## 致謝與參考

本課程設計參考了 Arduino 官方 Student Kit 教學系列與多個開源 Arduino/Tinkercad 教學社群資源的主題式專案精神，並依照工業管理系學生特性（具程式邏輯基礎、無深入電子電路背景）大幅調整教學節奏與情境包裝，感謝所有開放式教學社群的貢獻者。
